⏱ Recipe 1 — Timer Interrupt
Blink LED · Counter · MM:SS stopwatch · Periodic task

CubeMX:

1
TIM1 → Clock Source: Internal Clock · PSC=215, ARR=999 (= 1 ms, APB2 216MHz)
2
TIM1 NVIC: TIM1 update interrupt and TIM10 global interrupt ✓ · PreemptPriority=1 Sub=0
3
Optional TIM2 for slower flag (PSC=107, ARR=399999 → 400ms, APB1 108MHz)
/* USER CODE BEGIN 0 */
uint32_t ms = 0;
uint8_t  flag = 0;

/* USER CODE BEGIN 2 */
HAL_TIM_Base_Start_IT(&htim1);
HAL_TIM_Base_Start_IT(&htim2); /* optional */

/* USER CODE BEGIN WHILE */
while (1) {
  if (flag) {
    flag = 0;
    /* --- DO TASK HERE --- */
    uint32_t s = ms/1000, m = s/60;
    char b[32];
    int n = sprintf(b, "%02lu:%02lu\r", m, s%60);
    HAL_UART_Transmit(&huart3,(uint8_t*)b,n,100);
    HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
  }
}

/* --- CALLBACKS (outside main, in main.c) --- */
void HAL_TIM_PeriodElapsedCallback(
      TIM_HandleTypeDef *htim) {
  if (htim->Instance == TIM1) ms++;     /* 1ms */
  if (htim->Instance == TIM2) flag = 1; /* 400ms */
}
TIM1 ARR is 16-bit (max 65535). Use TIM2 for intervals >~300ms.

⚡ Recipe 2 — EXTI Button
Button press → instant action · Count presses · Toggle state

CubeMX:

1
PC13 → GPIO_EXTI13 (B1 button)
2
System Core → NVIC → Priority Group: NVIC_PriorityGroup_1
3
GPIO → PC13 → Mode: External Interrupt Rising edge · Pull: No pull
4
NVIC → EXTI line[15:10] interrupts ✓ · PreemptPriority=1 Sub=0
/* USER CODE BEGIN 0 */
uint32_t btn_count = 0;

/* No USER CODE BEGIN 2 needed for EXTI */

/* USER CODE BEGIN WHILE */
while (1) {
  /* can do other things here */
  /* btn_count is updated by interrupt */
  char b[32];
  int n = sprintf(b,"Count=%lu\r\n",btn_count);
  HAL_UART_Transmit(&huart3,(uint8_t*)b,n,100);
  HAL_Delay(200);
}

/* --- CALLBACK (outside main, in main.c) --- */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
  if (GPIO_Pin == GPIO_PIN_13) {
    btn_count++;
    HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
  }
}
No need to start anything — EXTI is always listening once CubeMX configures it.

〰️ Recipe 4 — ADC → PWM
Pot controls LED brightness · Servo · RGB color via ADC

CubeMX (add to ADC setup above):

1
TIM2 → Channel 3: PWM Generation CH3 · Clock Source: Internal Clock
2
PSC=107, ARR=9999, Pulse=2499, Mode=PWM mode 1, Preload=Enable
3
Pin: PB10 (NOT PA2 — conflict with UART2!). No NVIC needed.
4
Still need ADC1 configured (Recipe 3 steps 1–3)
/* USER CODE BEGIN 2 */
HAL_ADC_Start(&hadc1);
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_3);

/* USER CODE BEGIN WHILE */
while (1) {
  HAL_ADC_PollForConversion(&hadc1, 100);
  uint32_t adc = HAL_ADC_GetValue(&hadc1);

  /* Map 0–4095 → duty 20%–100% of ARR=9999 */
  float duty = 0.20f + (adc/4095.0f)*0.80f;
  uint32_t ccr = (uint32_t)(duty * 10000.0f);
  __HAL_TIM_SET_COMPARE(&htim2,
    TIM_CHANNEL_3, ccr);

  /* UART debug (optional) */
  char b[48];
  int n = sprintf(b,"ADC=%lu duty=%.0f%%\r\n",
    adc, duty*100.0f);
  HAL_UART_Transmit(&huart3,(uint8_t*)b,n,100);
}
Duty% = CCR/(ARR+1)×100. CCR=0 → always OFF. CCR=ARR → always ON.

RGB (TIM3, same PSC/ARR):

🌡 Recipe 6 — AM2320 Temp+Humidity → LCD
I2C sensor read · Parse raw bytes · Display on screen

CubeMX (add to LCD project):

1
Connectivity → I2C1 → I2C mode · Standard Mode (100 kHz)
2
No NVIC needed for polling I2C
/* --- FUNCTION (put above main) --- */
void read_am2320(float *temp, float *hum) {
  uint8_t cmd[3] = {0x03, 0x00, 0x04};
  uint8_t buf[8] = {0};

  /* 1. Wake sensor (NACK expected — IGNORE error) */
  HAL_I2C_Master_Transmit(&hi2c1,
    0x5C<<1, NULL, 0, 10);
  HAL_Delay(1);

  /* 2. Send read command */
  HAL_I2C_Master_Transmit(&hi2c1,
    0x5C<<1, cmd, 3, 10);
  HAL_Delay(2);

  /* 3. Read 8 bytes back */
  HAL_I2C_Master_Receive(&hi2c1,
    0x5C<<1, buf, 8, 10);

  /* Parse buf: [func,len,RH_H,RH_L,T_H,T_L,CRC_L,CRC_H] */
  *hum = ((buf[2]<<8)|buf[3]) / 10.0f;
  uint16_t rt = ((buf[4]&0x7F)<<8)|buf[5];
  *temp = (buf[4]&0x80) ? -(rt/10.0f) : rt/10.0f;
}

/* USER CODE BEGIN 2 */
ILI9341_Init();
ILI9341_FillScreen(WHITE);

/* USER CODE BEGIN WHILE */
float temp=0, hum=0;
char line[32];
while (1) {
  read_am2320(&temp, &hum);

  sprintf(line, "Temp: %.1f C  ", temp);
  ILI9341_WriteString(10,10,line,Font_11x18,BLACK,WHITE);
  sprintf(line, "Humi: %.1f %%  ", hum);
  ILI9341_WriteString(10,40,line,Font_11x18,BLACK,WHITE);

  HAL_Delay(500); /* don't spam sensor */
}
NACK on the wake step is NORMAL. HAL returns error — ignore it and continue.

buf[4] bit7 = sign flag (1=negative temp). buf[2..3]=humidity raw. Divide all by 10.0f.
