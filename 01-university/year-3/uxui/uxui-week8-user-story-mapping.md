## Part 1 — Scoping Topic

1. **Domain/industry:** Education tech
2. **Niche market:** Education tech → campus facility/room booking
3. **User group:**
   - Students who submit booking requests
   - Professors who need live room availability
   - University facility/admin staff who approve and manage rooms
4. **Narrow down users:**
   - Student club leaders submitting activity requests
   - Professors checking room status from their desk
   - Facility staff handling approvals, conflicts, and room maintenance status
5. **Critical user journey:** Check room availability → Submit booking request → Track approval status → (staff) Approve & manage bookings

**Final scope:** Design an app for KMITL students, professors, and facility staff to get live room availability and clear booking-status visibility, closing the gap where LINE messages sit unread and staff can't see room state.

## Part 3 — User Story Mapping

**Activities:** Log in → Browse & Check Rooms → Book a Room → Track Room Status

### Activity 1: Log in
Step: Enter info
- Enter student ID
- Enter password
- Press log in

### Activity 2: Browse & Check Rooms
Step: Browse rooms
- View room list
- Filter rooms

Step: Filter search
- Choose floor
- Filter by room type suited to activity (lecture / lab / meeting room)
- Filter by date
- Filter by time
- Filter by capacity

Step: Search by name *(for users who already know what they want)*
- Enter a room name

Step: Check availability
- Check if room is out of order
- See free status
- See occupied status

Step: View room detail
- View capacity
- View equipment
- View room photos

### Activity 3: Book a Room
Step: Select room & date
- Select a room
- Select booking date
- Select time slot

Step: Enter booking details
- Enter purpose/activity name
- Enter attendee count
- Attach activity form

Step: Submit booking
- Check time conflict
- Press submit
- Receive tracking confirmation

### Activity 4: Track Room Status
Step: Track approval status
- Check pending status
- Check approved status
- Check rejected status
- View rejection reason

Step: Get notified
- Receive notification on status change
- Receive alert when room auto-released

### Future Releases
- Log in: biometric/quick login
- Browse & Check Rooms: save favorite rooms, campus map view
- Book a Room: recurring booking, auto-fill from booking history
- Track Room Status: calendar export, similar-room suggestion after rejection
