## Checklist

- [ ] New device available in stock
- [ ] If user needs time to transfer files → **Technical Support** adds old device to **Loan** tab in TARS first
- [ ] User transfers files to OneDrive before handover
- [ ] User confirms all files are accessible on new device
- [ ] User returns old laptop → remove from Loan → hand to Assets Team
- [ ] Assets Team marks Set As Received in TARS + verifies in Kace
- [ ] New laptop built via Autopilot (see [[Windows Laptop Build]])
- [ ] Assign device and update status in Kace
- [ ] User signs for new device
