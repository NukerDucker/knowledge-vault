# AI Assignment: Romania-Map Pathfinding Web App

## 📌 Overview
The objective is to implement the **Romania-Map Pathfinding problem** as a functional **Web Application**. The application must allow users to select any arbitrary cities on the map as the start and goal states.

## ⚙️ Technical Requirements
You are required to implement and compare two different search strategies:
- **Blind Search:** One standard uninformed search algorithm.
- **Custom Heuristic Search:** A search algorithm using a **custom-designed heuristic**.

### Performance Comparison
The app must provide a comparison of these algorithms based on:
- **Execution time**.
- **Memory usage**.
- **Solution quality** (total path cost).
