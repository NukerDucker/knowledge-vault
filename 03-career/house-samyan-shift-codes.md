# House Samyan Shift Codes

## Rule: adding events

**Always check which calendar before creating.** Default to primary only if unsure and confirmed. Correct calendars:

| Event type | Calendar |
|------------|----------|
| Work shifts (House Samyan) | House Staff |
| University / coursework | Campus Life |
| Personal | Napaul Intharasing (primary) |
| Side gigs | Side Job |

---

## Calendar naming convention

`[ShiftCode] · [Location]`

Example: `MC · House Samyan`, `DHF · House Samyan`

Apply consistently to **all** events — work shifts and coursework alike — for unified planning view.

**Calendar:** House Staff (Google Calendar)

---

## Box Office (B)

| Code | Hours | Notes |
|------|-------|-------|
| DB   | 09:30–18:30 | Fixed |
| NB   | Last showtime + 9 hr + 10 min | Must not leave early regardless of customers |
| NHB  | Last showtime + 5 hr + 10 min | Must not leave early regardless of customers |

Example: last show 23:20 → NB = 14:30–23:30, NHB = 18:30–23:30

## Code structure

```
D  = Day
N  = Night
H  = Half (modifier)
M  = Midday
B  = Box Office
C  = Candy / Concession
F  = Floor
```
